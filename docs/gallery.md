# Gallery

The repository keeps code-only examples because resource files are intentionally not assumed to exist in this workspace.

Available examples:

- `examples/java/SettingsScreenExample.java`
- `examples/slate/settings.slate`
- `common/src/main/slate/gallery.slate`

Screenshots and GIFs should be captured from a local Minecraft client using the owning mod or resource pack assets. Do not commit generated placeholder textures just for documentation.
