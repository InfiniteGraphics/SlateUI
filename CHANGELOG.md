# Changelog

All notable changes are tracked here by release tag.

## 0.3

- Tightened `.slate` compiler validation and authoring diagnostics.
- Added texture region authoring for images.
- Documented resource override scope and stability boundaries.

## 0.2

- Introduced host, clipboard, text measuring, render, and interaction abstractions.
- Routed draw commands through a renderer adapter.
- Preserved `SlateText` through rendering commands for Minecraft-side conversion.

## 0.1

- Stabilized the screen runtime, core components, style merge semantics, token resolution, input basics, focus traversal, scroll bounds, and diagnostics.
- Made missing button commands non-destructive.
- Added real texture draw commands for images.
